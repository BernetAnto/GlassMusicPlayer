# GlassMusicPlayer

A Flutter starter for a premium dark glassmorphism music player.

## Included in this starter
- Dark AMOLED-inspired glass UI
- Home, Search, Library and Lyrics sections
- Sample Tamil and English track cards (display examples only)
- Mini-player interaction mockup
- Glass cards with blur and transparency

## Run locally
1. Install Flutter SDK.
2. Extract this ZIP.
3. Open the extracted `GlassMusicPlayer` folder in VS Code or Android Studio.
4. Run `flutter pub get`.
5. Run `flutter run`.

## Important
This is the UI starter, not yet a fully working audio player. Device music scanning, audio playback/background controls, real trending charts and licensed/saved synchronized lyrics are planned for the next development phases. Sample track names are illustrative; no copyrighted audio or lyrics are bundled.
